# Rispa

Rispa is a React + Vite landing page project inspired by the visual language of `softtop.tech`, rebuilt with the requested `9278-clone` file structure and branded for Rispa.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `public/` static assets
- `src/components/` page sections and shared UI
- `src/data/` content sources
- `src/styles/globals.css` design system and layout styling
